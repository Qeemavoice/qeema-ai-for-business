# Qeema AI for Business (قيمة فويس)

منصة عربية للتعليق الصوتي: أصوات بشرية + أصوات AI + استوديو TTS + لوحة عميل. الواجهة عربية RTL بالكامل.
المالكة: نور (Qeema Digital Production). اكتب النصوص الظاهرة للمستخدم بالعربية دائماً.

## التشغيل
- `npm install` ثم `npm run dev` (يشغّل `server.ts`: Express + Vite middleware على http://localhost:3000)
- فحص الأنواع: `npm run lint` (= `tsc --noEmit`) ويجب أن يمر بعد كل تعديل
- لا يوجد اختبارات آلية؛ تحقق من الصفحات في المتصفح

## البنية
- `src/` واجهة React 19 + react-router-dom 7 + Tailwind 4 + lucide-react
  - `src/pages/` صفحات الموقع العام (كل صفحة تستدعي `useSeo(STATIC_SEO_ROUTES[...])`)
  - `src/seo/seoConfig.ts` إعدادات SEO لكل مسار؛ أضف مدخلاً عند إنشاء أي صفحة جديدة
  - `src/components/dashboard/` أقسام لوحة العميل، و`ClientDashboardView.tsx` يجمعها
  - `src/App.tsx` المسارات
- `server/` + `server.ts` خادم Express وقاعدة بيانات في الذاكرة (`server/db/store.ts`)
  - تعديلات الداش تُحفظ في `data/db.json` بعد كل طلب كتابة وتُحمَّل عند التشغيل (`server/db/persist.ts`). القصص الجديدة في `src/data/stories.ts` تُضاف تلقائياً، والمحذوف من الداش لا يرجع. تعديل حقل موجود لقصة محفوظة يتم من الداش (النسخة المحفوظة تغلب الكود)، أما الحقول الجديدة المضافة في الكود فتُكمَّل تلقائياً. أسرار التكاملات (Stripe/SMTP) لا تُكتب في الملف.
- `shared/plans.ts` مصدر وحيد للباقات (يستخدمه الخادم والواجهة: الأسعار، الفوترة، الإدارة). عدّل الباقات هنا فقط
- `integrations/qeema-voice-chat/` حزمة Laravel للشات (لم تُشغَّل بعد)
- `public/qv-chat/qv-chat.js` ويدجت "مساعد قيمة" (وضع تجريبي `data-mock="true"` في `index.html`). الفتح من الكود: `openAssistant()` في `src/lib/assistantEvents.ts`

## قواعد المنتج المتفق عليها
- الباقات: مجاني، مبتدئ $20 (25,000 حرف)، صانع محتوى $30 (50,000 حرف + خصم 15% على حجوزات المعلقين)، الشركات (سعر مخصص). رصيد ترحيبي 5,000 حرف لكل مستخدم جديد
- لا يوجد استنساخ صوت ولا API ولا صفحة شات بوت مستقلة ولا لوحة معلق داخل لوحة العميل
- الحجز: صفحة مستقلة لكل عينة `/ar/booking/:slug`. نعرض اسم العينة وليس اسم المعلق. العدّاد بالحروف (التشكيل والمسافات تُحسب)، كل 100 حرف = دقيقة، سعر الدقيقة مؤقتاً $40
- الدفع: Stripe. المتاح Visa وMastercard وApple Pay وGoogle Pay. لا مدى ولا PayPal. زر "ادفع الآن" حالياً يعرض تأكيداً فقط (بدون دفع حقيقي)
- اللهجات: مصدرها مكتبة الأصوات `getShortDialect` في `VoiceLibraryView.tsx`. الأزرار البرتقالية `bg-[#FF5500]`
- صفحة "كيف نعمل" = `/ar/booking-steps`، وسياسة التعديلات = `/ar/p/revisions-policy`
- الإلغاء (معتمد 2026-10-27): قبل تحويل الحجز للمعلق استرداد كامل بعد خصم رسوم بوابة الدفع، بعد التحويل وقبل التسليم 50%، بعد التسليم لا استرداد. النص في `src/data/sitePages.ts` (شروط الاستخدام)

## معلّق / للإكمال
- أصوات AI مخفية مؤقتاً (تبويب المكتبة، قسم الرئيسية، رابط الهيدر). الكود محفوظ؛ للتفعيل: `AI_VOICES_ENABLED = true` في `shared/features.ts`
- ربط Stripe الحقيقي، وسعر الدقيقة الفعلي
- نشر خادم Laravel للشات وتبديل `data-mock` بـ `data-endpoint`، ورقم واتساب الدعم `data-whatsapp`
- زر المساعد أسفل اليمين يغطي مربع الرصيد في لوحة العميل (قرار: إخفاؤه داخل اللوحة أو رفعه)
- سياسة التعديلات تذكر "محادثة المشروع" وهي غير موجودة بعد
- ملف `upd3.zip` الزائد في جذر المشروع يُحذف يدوياً

## أسلوب العمل
- غيّر أقل قدر ممكن من الملفات، واحترم أنماط الملفات المجاورة
- بعد أي تعديل: `npm run lint` ثم افتح الصفحة المتأثرة
