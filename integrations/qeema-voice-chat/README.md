# مساعد قيمة — شات اختيار الصوت

حزمة تُركَّب فوق موقع قيمة فويس الحالي (Laravel). يبدأ الشات بسؤال المستخدم: هل هو عميل أم معلق صوتي؟

- **العميل:** يصف مشروعه، فيرشّح له الشات أنسب المعلقين، ويُسمعه معاينة قصيرة بصوت المعلق المستنسخ على جزء من نصه، ثم يرسل طلب الحجز للفريق.
- **المعلق:** يتعرف على المنصة والاستنساخ المرخّص، ويُوجَّه لإنشاء حساب معلق وإضافة عيناته، أو يُحوَّل لموظف الدعم إذا كان سؤاله عن حسابه أو أرباحه.

الحزمة لا تعدّل أي جدول أو ملف موجود في الموقع. كل جداولها تبدأ بـ `qv_chat_`.

---

## المتطلبات

- PHP 8.0 أو أحدث، وLaravel 8 أو أحدث.
- مفتاح API من Anthropic (أو OpenAI)، ومفتاح API من ElevenLabs.
- أن يكون مجلد `storage` قابلًا للكتابة (هو كذلك في أي موقع Laravel يعمل).

| المسار | الوظيفة |

## خطوات التركيب

### 1. نسخ الملفات

انسخي هذه المجلدات إلى جذر مشروع الموقع كما هي:

```
app/QeemaChat        →  app/QeemaChat
config/qeema_chat.php  →  config/qeema_chat.php
database/migrations/2026_10_24_000001_create_qv_chat_tables.php  →  database/migrations/
public/qv-chat       →  public/qv-chat
```

### 2. تسجيل الحزمة

- **Laravel 11 أو أحدث:** أضيفي هذا السطر إلى `bootstrap/providers.php`:
  ```php
  App\QeemaChat\QeemaChatServiceProvider::class,
  ```
- **Laravel 10 أو أقدم:** أضيفيه إلى مصفوفة `providers` في `config/app.php`.

### 3. المفاتيح

انسخي محتوى `env.example` إلى آخر ملف `.env` في الموقع، واكتبي المفاتيح. ثم:

```bash
php artisan config:clear
```

### 4. إنشاء الجداول

```bash
php artisan migrate
```

### 5. إدخال المعلقين

صدّري شيت بيانات المعلقين إلى CSV بنفس أعمدة `samples/talents-sample.csv`، ثم:

```bash
php artisan qv-chat:import-talents storage/app/talents.csv --dry-run   # فحص فقط
php artisan qv-chat:import-talents storage/app/talents.csv             # حفظ
```

- يمكن إعادة الاستيراد بعد كل تحديث للشيت؛ المعلق يُحدَّث حسب `talent_code`.
- اللهجات والاستخدامات تُكتب بالعربية أو بالرموز، ويُفصل بينها بفاصلة منقوطة: `سعودي نجدي;فصحى`.
- النبرات من هذه القائمة فقط: حماسي، دافئ، رسمي، ودود، إخباري، درامي، طفولي، هادئ، واثق، فخم.
- المعلق المستنسخ لا يُستورد إلا إذا كان له `elevenlabs_voice_id` و`clone_consent_date`.
- `sample_url` يجب أن يكون رابطًا يعمل للعينة البشرية. تأكدي أن العينات نُقلت من DigitalOcean قبل الاستيراد.

### 6. إضافة الشات للموقع

أضيفي هذا السطر قبل `</body>` في القالب الرئيسي للموقع:

```html
<script src="/qv-chat/qv-chat.js" defer></script>
```

يظهر زر الشات في أسفل يمين الصفحة. لنقله لليسار أضيفي `data-position="left"`.

لربط أي زر في الموقع بالشات، مثل «جرّب الآن» أو «توليد الصوت الآن» في الصفحة الرئيسية:

```html
<button onclick="QeemaChat.open()">جرّب الآن</button>
<!-- أو افتحيه مع رسالة جاهزة -->
<button onclick="QeemaChat.open('أريد صوتًا لإعلان سعودي')">إعلان سعودي</button>
```

### 7. التجربة

1. افتحي الموقع وابدئي محادثة.
2. عند طلب المعاينة سيظهر نموذج الرقم. مع `QV_CHAT_OTP_DRIVER=log` يُكتب رمز التحقق في `storage/logs/laravel.log`.
3. بعد التأكد من كل شيء، فعّلي إرسال الرمز بالواتساب (الخطوة التالية).

## إرسال رمز التحقق بالواتساب

غيّري `QV_CHAT_OTP_DRIVER=webhook` واكتبي في `QV_CHAT_OTP_WEBHOOK` عنوانًا يستقبل:

```json
{ "phone": "+9665xxxxxxxx", "code": "4821", "message": "رمز التحقق من قيمة فويس: 4821 ..." }
```

ويرسل `message` إلى `phone` بالواتساب. يمكن أن يكون هذا العنوان وكيل الواتساب الخاص بقيمة، أو سيناريو في n8n أو Zapier.

## إشعارات الفريق

كل طلب جديد أو تحويل للدعم:
- يُحفظ في جدول `qv_chat_requests` (النوع: `order_human` أو `order_ai` أو `handoff` أو `artist_support`).
- يُرسل بريدًا إلى `QV_CHAT_TEAM_EMAIL` (يعتمد على إعدادات البريد الموجودة في الموقع).
- يُرسل إلى `QV_CHAT_NOTIFY_WEBHOOK` إن وُجد.

## قواعد الرصيد والحماية (مطبّقة في الخادم)

| القاعدة | القيمة الافتراضية | أين تُعدّل |
| --- | --- | --- |
| طول المعاينة | 450 حرفًا (نحو 30 ثانية) من أول السيناريو | `QV_CHAT_PREVIEW_MAX_CHARS` |
| معاينات مجانية لكل رقم | 3 طوال عمر الحساب، لا تتجدد | `QV_CHAT_FREE_PREVIEWS` |
| معاينة إضافية بعد أول طلب | 1 | `config/qeema_chat.php` |
| حد الجهاز الواحد | 3 (يمنع التسجيل بأرقام متعددة) | `config/qeema_chat.php` |
| حد عنوان IP في اليوم | 6 | `config/qeema_chat.php` |
| رسائل المحادثة الواحدة | 40 | `config/qeema_chat.php` |
| صلاحية رابط المعاينة | 24 ساعة، بلا زر تحميل | `config/qeema_chat.php` |
| تكرار نفس المعاينة | يُعاد نفس الملف بدون خصم | تلقائي |

النص الكامل بصوت AI لا يُولَّد من الشات أبدًا. يُرسل كطلب `order_ai` للفريق، ويُولَّد بعد الدفع.

## التحويل لموظف الدعم عبر الواتساب

للعملاء فقط. الشات يُكمل المحادثة بنفسه في الحالات المعتادة، ويحوّل العميل لموظف الدعم فقط عند:
طلب العميل لشخص بعد عرض المساعدة، شكوى أو مشكلة دفع، عقد مؤسسي أو فاتورة رسمية، دبلجة بعدة أصوات أو مشروع فوق 60 دقيقة، نص يحتاج مراجعة، أو تعطّل الأدوات مرتين.

عند التحويل يظهر للمستخدم زر «تواصل مع الدعم على الواتساب». يفتح الزر محادثة مع رقم `QV_CHAT_SUPPORT_WHATSAPP`، وفيها رسالة جاهزة برقم الطلب وملخصه، فلا يحتاج الموظف أن يسأل من جديد. التحويل لا يحتاج توثيق الرقم، والشات يبقى متاحًا بعده.

نص رسالة التحويل في `config/qeema_chat.php` ← `messages.handoff`.

## مسار المعلقين

- **الانضمام:** لا يجمع الشات بيانات المعلق. يعرض له بطاقة فيها: زر «أنشئ حساب معلق»، ومقال «كيف أنضم إلى منصة قيمة فويس؟»، وشروط قبول العينات الصوتية. المعلق ينشئ حسابه ويضيف عيناته بنفسه.
- **الأسئلة:** يجيب الشات بإيجاز، ثم يعرض رابط الشروط وسياسة الاستخدام ورابط المدونة، لأن الإجابات التفصيلية هناك. هذا يشمل الأرباح والنسب ومواعيد الدفع.
- **المشكلات:** إذا واجه المعلق مشكلة (أرباح لم تصل، تعذر رفع العينات، مشكلة في الحساب)، يرسل طلب دعم من الشات بعد تأكيد رقمه، ويُبلَّغ أن الرد خلال 48 ساعة. الطلب يُحفظ في `qv_chat_requests` بنوع `artist_support` ويصل للفريق بالبريد.
- **لا تحويل للواتساب للمعلقين.** الواتساب للعملاء فقط.
- الروابط في `.env`: `QV_CHAT_ARTIST_SIGNUP_URL` و`QV_CHAT_ARTIST_GUIDE_URL` و`QV_CHAT_TERMS_URL` و`QV_CHAT_BLOG_URL`. رابط شروط العينات مضبوط مسبقًا.
- المعلومات التي يقولها الشات للمعلقين في `SystemPrompt.php` ← «مسار المعلق الصوتي».

## تبديل المزود

```
QV_CHAT_PROVIDER=openai
OPENAI_API_KEY=...
QV_CHAT_OPENAI_MODEL=اسم النموذج
```

التعليمات والأدوات نفسها تعمل مع المزودين بلا أي تعديل آخر.

## قبل الإطلاق

- [ ] اختبار نموذج المعاينة `eleven_flash_v2_5` على اللهجات. إذا كان النطق ضعيفًا في لهجة ما، غيّري `QV_CHAT_PREVIEW_MODEL` إلى `eleven_multilingual_v2` (يستهلك ضعف الرصيد).
- [ ] تسجيل ملف العلامة الصوتية «معاينة من قيمة فويس» بنفس صيغة mp3 (44.1kHz، 128kbps) وكتابة مساره في `QV_CHAT_WATERMARK_PATH`.
- [ ] كتابة رقم واتساب الدعم في `QV_CHAT_SUPPORT_WHATSAPP`.
- [ ] مراجعة نصوص ما بعد الطلب في `config/qeema_chat.php`.
- [ ] ربط إرسال رمز التحقق بالواتساب.
- [ ] تجربة 20 محادثة حقيقية ومراجعة جدول `qv_chat_conversations` لتحسين التعليمات.
- [ ] كتابة روابط: صفحة إنشاء حساب المعلق، ومقال «كيف أنضم إلى منصة قيمة فويس؟»، والشروط وسياسة الاستخدام، والمدونة في `.env`.

## ما لا تتضمنه الحزمة

- **الدفع:** الطلب يصل للفريق، والفريق يرسل رابط الدفع. يمكن ربط بوابة دفع لاحقًا.
- **لوحة تحكم للطلبات:** الطلبات في جدول `qv_chat_requests` وفي البريد. يمكن عرضها في لوحة التحكم الحالية.
- **فحص المحتوى المتقدم:** الشات يرفض النصوص المسيئة حسب تعليماته، ويمكن إضافة كلمات ممنوعة في `blocked_terms`.
